# Hestia

Hestia is a client for **Minecraft: Java Edition** made for players on 1.8.x PvP servers. It runs the current
Minecraft client (26.3) with Fabric and makes it play, look and sound like 1.8.9 on those servers.

## What it is

- **Hestia.exe**, a Windows launcher. It signs the player in with their own Microsoft account, downloads and checks
  the official game files from Mojang, installs Fabric Loader and the mods Hestia needs, converts the player's 1.8
  resource packs, and starts the game.
- **The Hestia mod**, which brings back 1.8.9's combat timing, movement, visuals and sounds on 1.8.x servers,
  connecting through ViaFabricPlus.

## Sign-in and privacy

- Players sign in with their own Microsoft account in their own browser, the same way as with the official
  launcher (OAuth 2.0 authorization code flow with PKCE).
- Hestia uses the Microsoft, Xbox Live and Minecraft services only to sign the player in, check that the account owns
  Minecraft: Java Edition, and load the player's profile.
- Sign-in tokens stay on the player's PC, encrypted for their Windows user account. Hestia runs no servers of its own
  and collects no data.
- Hestia doesn't bypass authentication, license checks or any safety features.

## Availability

Hestia is in private development. This page is for information only: there are no downloads and no source code here.
